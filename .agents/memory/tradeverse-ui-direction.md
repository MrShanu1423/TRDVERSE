---
name: TradeVerse visual direction
description: Product-level visual direction for future TradeVerse screens and UI refinements.
---

TradeVerse should feel like a compact professional trading cockpit rather than a spacious generic dashboard: dark midnight surfaces, electric blue for general market actions, neon orange for crypto emphasis, teal profit states, dense bento panels, ticker data, quick actions, and responsive mobile-first navigation.

**Why:** The user explicitly wants a more beautiful, high-density experience influenced by modern Groww, CoinDCX, and Angel One trading interfaces.

**How to apply:** Keep live-data surfaces visually prioritized, use monospace typography for prices and percentages, preserve paper-trading safety messaging, and avoid returning to a light, low-information dashboard unless the user asks for a theme change.
