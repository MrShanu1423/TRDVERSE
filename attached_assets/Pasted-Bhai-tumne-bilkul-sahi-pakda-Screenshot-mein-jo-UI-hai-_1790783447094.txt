# 🎨 Complete UI/UX Master Prompt: "TradeVerse" — Premium Redesign

**Instruction:** *"You are an elite UI/UX designer and frontend engineer. Redesign the TradeVerse web app to be a world-class, professional, and highly engaging trading platform. The current design is too generic and spacious. The new design must combine the trust and clarity of Angel One with the sleek, modern, high-data-density feel of CoinDCX. The user must feel a 'wow' factor the moment they open it."*

### 1. DESIGN SYSTEM (STRICT TOKENS)

**Theme & Colors:**
- **Default Mode:** Sleek Dark Mode (Deep Midnight `#0B0E14`, Card `#151A22`, Border `#222A35`).
- **Light Mode:** Clean White (`#FFFFFF`), Card `#F8F9FA`, Border `#E5E7EB`.
- **Primary Accent:** Electric Blue (`#3B82F6`) for stocks/general, and Neon Orange (`#FF7139`) for crypto.
- **Action Colors:** Success/Profit `#10B981` (Green), Error/Loss `#EF4444` (Red).
- **Text:** Primary `#F9FAFB` (Dark) / `#111827` (Light). Muted `#9CA3AF`.
- **Glassmorphism:** Use `backdrop-filter: blur(12px)` with `rgba(21, 26, 34, 0.7)` for floating panels.

**Typography:**
- **Font:** `Inter` (UI) + `JetBrains Mono` (for numbers/prices to prevent layout shift).
- **Sizes:** Heading 1: 24px/700, Heading 2: 18px/600, Body: 14px/400, Caption: 12px/400, Price: 16px/600 (tabular-nums).

**Layout & Spacing (8pt Grid):**
- **Compact Density:** Reduce padding. Cards should have `16px` padding, not `24px`.
- **Bento Grid:** Use CSS Grid to create a dashboard where cards have varying heights and widths (like Apple Wallet or modern fintech).
- **Border Radius:** Cards `12px`, Buttons `8px`, Badges `999px`.

### 2. SCREEN-BY-SCREEN UI/UX REQUIREMENTS

#### A. TOP NAVIGATION (Global)
- **Left:** Logo + "TradeVerse" (bold).
- **Center:** Global Search Bar (magnifying glass, "Search stocks, crypto, F&O, MF...", `Ctrl+K` shortcut).
- **Right:** Live Market Status indicator (Green dot "Market Open"), Notifications bell, Profile avatar.
- **Ticker Tape:** A scrolling marquee right below the nav bar showing live prices of Nifty 50, Sensex, BTC, ETH, and top gainers. (This gives an immediate "live" feel).

#### B. DASHBOARD (Home) - Bento Grid Layout
- **Hero Card (Left, 60% width):** "Total Portfolio Value" with a subtle gradient background. Large `JetBrains Mono` price. Below it, a **live sparkline chart** (SVG) showing today's performance. Quick action buttons: `[+ Add Funds]` `[Withdraw]` `[Trade]`.
- **Quick Stats (Right, 40% width):** Two smaller cards stacked.
    - Card 1: "Invested Capital" + "Day's P&L" (Green/Red text with an arrow icon).
    - Card 2: "Portfolio Health" — A sleek circular progress bar (like CoinDCX) with a score out of 100 and a "Rebalance" button.
- **Watchlist Card (Full Width):** 
    - Tabs: `All` `Crypto` `Stocks` `F&O`.
    - Table view with columns: Asset (Icon + Name), Price, 24h Change (Green/Red pill), 7d Sparkline, Action (`Buy` / `Sell` buttons).
    - **Hover Effect:** Row background lightens, and a "Quick Trade" button appears.
- **Market Movers (Bottom Left, 50%):** Top Gainers / Losers list with mini bar charts.
- **News & Insights (Bottom Right, 50%):** Scrolling feed of news with source logos and time.

#### C. TRADING TERMINAL (The Core Feature)
*This is where Angel One + CoinDCX merge. It must be powerful but not overwhelming.*
- **Layout:** 3-column layout on desktop.
- **Left Column (Watchlist & Order Book):** 
    - Searchable watchlist with drag-and-drop.
    - Real-time Order Book (Bids/Asks) with depth chart (green/red bars).
- **Center Column (The Chart):** 
    - Full TradingView integration.
    - Timeframes: `1m` `5m` `15m` `1H` `4H` `1D` `1W`.
    - Indicators dropdown (RSI, MACD, Bollinger Bands, EMA).
    - Drawing tools toolbar on the left edge.
- **Right Column (Order Execution Panel):**
    - **Toggle:** `Buy` (Green) / `Sell` (Red).
    - **Order Type:** `Market` | `Limit` | `Stop-Loss` | `OCO`.
    - **Inputs:** Price, Quantity, Trigger Price.
    - **Leverage Slider:** (For F&O/Crypto Futures) with a warning label for high leverage.
    - **Margin Required:** Live calculation.
    - **Slide to Confirm:** A large, animated slider button at the bottom. "Slide to Buy BTC".
    - **Positions/Orders Tab:** Below the execution panel, a tabbed view showing `Open Orders` | `Positions` | `Order History`. Swipe to cancel.
- **Bottom Panel (Portfolio):** A collapsible drawer showing total margin used, available balance, and quick P&L.

#### D. MARKETS SCREEN (Angel One Style)
- **Top Tabs:** `Stocks` | `F&O` | `Mutual Funds` | `IPO` | `ETFs` | `Crypto` | `US Stocks`.
- **Filters:** Sector, Market Cap, Volume, Gainers/Losers.
- **Table:** Data-dense table. Columns: Symbol, LTP, Change, Volume, P/E, Market Cap, Action.
- **IPO Section:** Cards for upcoming IPOs with GMP (Grey Market Premium) in green, lot size, and `Apply Now` button.
- **Mutual Funds:** SIP calculator, Fund comparison (side-by-side), and "Top Rated" carousel.

#### E. PORTFOLIO SCREEN
- **Unified View:** A pie chart showing asset allocation (Stocks 40%, Crypto 30%, MF 20%, F&O 10%).
- **Holdings Table:** Sortable by P&L, Invested, Current Value.
- **Tax Optimizer:** A small card that says "You can save ₹X in taxes by harvesting losses." with a `Review` button.
- **SIP Manager:** List of active SIPs with `Next Debit Date`, `XIRR`, and `Pause/Modify` buttons.

### 3. MICRO-INTERACTIONS & ANIMATIONS (The "Wow" Factor)
- **Price Flash:** When a price updates via WebSocket, the number should flash Green (uptick) or Red (downtick) for 300ms.
- **Number Roll:** When the portfolio value changes, the digits should roll up/down smoothly (like a slot machine).
- **Slide to Confirm:** The thumb should have a satisfying haptic-like visual feedback when dragged.
- **Skeleton Loaders:** Instead of spinners, use shimmering skeleton screens while data loads.
- **Hover States:** Buttons should have a subtle `transform: translateY(-2px)` and shadow on hover.
- **Toast Notifications:** "Order Executed successfully" slides in from the top right with a green checkmark.

### 4. RESPONSIVE DESIGN (Mobile & Tablet)
- **Mobile:** Bottom navigation bar (Home, Markets, Trade, Portfolio, Profile). The Trade screen becomes a full-screen modal with a bottom sheet for order execution.
- **Tablet:** 2-column layout (Watchlist + Chart). Order execution is a floating action button (FAB) that expands into a panel.
